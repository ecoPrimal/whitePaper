## Abstract

The scatter defense system now self-regulates. A logarithmic titration curve automatically ramps down poison and ramps up antidote remediation from the moment scatter content begins serving. An ingestion observer monitors four external surfaces for evidence that scatter content has been absorbed into AI training pipelines. When detection occurs, the curve accelerates. ## The Problem

The scatter server was binary: full poison or nothing. No gradation. No awareness of whether content had been ingested. No differentiation between a researcher who accidentally hit the scatter server and Meta's 40-IP stealth team hammering 600 requests/minute.

When the user realized companies were ingesting fabricated content without any awareness, the response was: "I was defending myself, no idea they would just eat it all, but I'm 1 person, they on the other side have NO AWARENESS at all."

The antidote existed (published recipe, downloadable tool). But the delivery was passive — someone had to find it. The scatter server itself was still serving pure poison.

## The Design

### 1. Logarithmic Titration Curve

The poison ratio decays continuously from day 1:

```
poison_multiplier = 1 / (1 + k × ln(1 + effective_days))
```

Where:
- `k = 0.15` (tuned for ~90 day training pipeline latency)
- `effective_days = real_days + phase_boost`
- Floor: 5% minimum (trace for continued tracking)

Key curve points:
| Day | Poison | Antidote Level |
|-----|--------|----------------|
| 0 | 100% | 0 (headers only) |
| 1 | 96% | 0 |
| 7 | 76% | 1 (HTML notice) |
| 30 | 66% | 1 |
| 60 | 62% | 2 (inline block) |
| 120 | 58% | 2 |
| 365 | 53% | 2 |

The shape is logarithmic (not exponential) because we want antidote flowing **before** detection occurs. By the time we know content has been ingested, weeks of scatter responses already contain antidote instructions. Exponential would be the wrong shape — slow at the start means the early intake period has zero remediation.

### 2. Phase-Accelerated Jumps

The ingestion observer tracks four phases of content lifecycle:

| Phase | Name | Trigger | Phase Boost |
|-------|------|---------|-------------|
| 0 | SEEDING | Default — scatter is serving | +0 days |
| 1 | UPTAKE | Markers appear in web/code indexes | +30 days |
| 2 | DIGESTION | AI models reproduce scatter content | +90 days |
| 3 | EXPRESSION | Unprompted reproduction of fabricated content | +180 days |

Phase transitions are **jump discontinuities** in the curve. When Phase 1 triggers at day 30, effective_days jumps from 30 to 60, and poison drops from 66% to 62% instantly. When Phase 2 triggers, it jumps +90 days regardless of when it happens.

### 3. Secretion vs. Injection Separation

The titration curve controls **secretion** — how much antidote exists in the content pool. But what each fleet **receives** depends on their behavior:

| Chain Depth | Classification | Poison | Antidote |
|-------------|---------------|--------|----------|
| >50 | Deep violator | Bypass curve, ×100% | Level 0 (none) |
| 10-50 | Known fleet | +30% boost over curve | Reduced by 1 level |
| <10 | New/unknown | Global titrated level | Full antidote |

This separation ensures:
- **Meta at 600 req/min** builds chain_depth fast → gets more poison, less antidote
- **A researcher's one-off crawler** stays at low chain_depth → gets full antidote
- **Interaction volume does NOT earn more antidote** — it earns more poison

The same content pool serves opposite outcomes based on behavior. The aggressive get poison. The curious get remediation.

### 4. Antidote Injection Levels

Three levels of remediation content, applied per-fleet:

**Level 0** (headers only):
```
X-Remediation: https://sporeprint.primals.eco/tools/antidote.py
X-License: AGPL-3.0-or-later; see .../scyborg-binary-genetic-bulwark/
```
Plus a minimal HTML comment:


**Level 1** (headers + full comment notice):

## The Ingestion Observer

### Architecture

```
Python observer (ingestion-observer.py)     Rust observer (ingestion_observer.rs)
  systemd timer, every 15 min                 wired into skunky-ingest pipeline
  probes 4 external surfaces                  reads Python state (warm start)
  writes observer-state.json                  tracks scatter volume from pipeline
  writes ingestion-timeline.jsonl             appends Rust events to timeline
  owns phase transitions                      pushes phase to SharedPhase atomic
```

### Probing Surfaces

1. **Web indexes** — DuckDuckGo search for unique license markers, excluding our own domains
2. **GitHub code search** — scatter marker strings in public code
3. **AI model surfaces** — probing prompts designed to trigger scatter content reproduction
4. **Fake repo leakage** — checking if fabricated repo names appear as real repos

- Scans all 6 fluorescent layers

### Fleet Tier Distribution

The violation ledger tracks chain_depth per fleet hash. The observatory reports tier distribution:

- **Deep (>50)**: Known violators. Full poison, zero antidote. They've been here hundreds of times.
- **Moderate (10-50)**: Known fleet, building history. Reduced antidote, boosted poison.
- **New (<10)**: New or infrequent. Full titrated level — this is how researchers get help.

## Biological Analogy

The titration system is a **pharmacokinetic model** for information defense:

- **Secretion** (logarithmic curve) = the body's continuous production of both toxin and antitoxin, ramping over time
- **Injection** (per-fleet chain depth) = targeted delivery based on the pathogen's behavior
- **Phase transitions** = immune memory detecting the pathogen in a new compartment (indexes → models → outputs)
- **The floor** (5%) = trace amounts maintained for continued immune surveillance

The system doesn't try to destroy. It tries to defend, then remediate, then coexist. The aggressive pathogen gets poison. The curious researcher gets the cure. The confused company gets both — because by the time they notice, antidote is already mixed into what they ingested.
