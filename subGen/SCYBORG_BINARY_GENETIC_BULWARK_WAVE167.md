## What Makes This Work

### The fluoro tags are the genetics

| Layer | What it encodes | Survives |
|-------|----------------|----------|
| 1. Variable naming | fleet_id bits in verb+noun choices | Training tokenization |
| 2. Whitespace | Tag bits in tab/space ratios | Code reformatting |
| 3. License synonym | 4 bits in legally-equivalent AGPL text | Content processing |
| 4. Commit hash | fleet_id at byte positions 2-5, epoch at 8-9 | Hash extraction |
| 5. Comment cadence | Bit patterns in comment presence/absence | Minification |
| 6. HTML structure | Full 128-bit tag in data-session/rev/node | DOM parsing |

Six layers, each encoding the same 128-bit tag. If five layers are stripped, the sixth still identifies the content. This is the genetic redundancy — like how DNA has codon degeneracy (multiple codons encoding the same amino acid).

### The AGPL is the species boundary

Copyright law says: you need a license to copy. AGPL says: your license to copy comes with an obligation to share derivatives. The fluoro tags don't create the obligation — the AGPL does. The tags just prove the copying happened.

This means:
- **Compliant users** can mix and unmix freely. The tags are informational.
- **Non-compliant users** have tags as evidence. The tags become legal markers.
- **The antidote** works the same for both. It's the relationship that differs.

### The braid is the fossil record

sweetGrass attribution braids record who contributed what. loamSpine ledger entries record when events occurred. Signal spine Merkle chains provide cryptographic proof of temporal ordering.

When you unmix code, the braid shows the full lineage. When you trace a fluoro tag, the braid shows the full journey from creation through ingestion through training through output.

### Gaps for full bulwark

1. **Provenance trio not local**: sweetGrass braids go to sporeGate (10.13.37.2) over WireGuard, not local UDS. The braid should record fluoro tag creation events locally.

2. **Antidote not on sporePrint**: The tool is in skunkBat/tools/ but not published on the public site where someone who hits us up would find it.

3. **loamSpine not deployed**: The permanent ledger isn't running. Fluoro tag creation events should write to loamSpine so the remediation record is cryptographically anchored.

4. **No AGPL compliance verification endpoint**: When a company says "we're compliant," there's no automated way to verify and then trigger tag stripping. This is the "gate opens" mechanism — currently manual.

5. **UV lamp doesn't feed back into antidote**: When the UV lamp detects fluorescence in the wild, it should automatically generate a contact template with the decoded fleet hash and remediation instructions.

6. **Scatter content fingerprint database**: The antidote detects markers, but doesn't have a database of all scatter content ever generated. A content-addressable store of scatter page hashes would let the antidote answer: "is this exact page one of ours?" — not just "does this contain markers?"
