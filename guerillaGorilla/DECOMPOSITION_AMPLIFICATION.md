## The Transition: Gorilla → Ecosystem

The gorilla's analytical weight serves two functions:

1. **Credibility** — Every LARA number, FEC filing, and docket
   entry is verifiable. No community group risks amplifying
   unsubstantiated claims. The weight is the credibility.

2. **Specificity** — Each published page contains data specific
   to one community's enzymatic function. The dykema-chronology
   page contains dark money data. The words-vs-numbers page
   contains education data. The foiaworks-warning page contains
   FOIA data. The gorilla pre-digests the substrate into forms
   each organism can metabolize directly.

The transition from analytical weight to ecosystem pressure is
not a handoff. It is a **phase transition** — the same data
changes state from organized information (solid) to distributed
action (gas). The gorilla does not control the gas phase. The
gorilla's work is complete when the substrate is published.

Barrett's congressional office, Ellison's platform) can retaliate
against a single attacker. It cannot retaliate against 15
independent organisms metabolizing its structure from 15
directions simultaneously.

The gorilla's contribution to the diffraction is:
1. Produce substrate (analytical weight)
2. Publish substrate (sovereign sites, no platform dependency)
3. Deliver substrate to decomposers (storm + wildfire)
4. Observe decomposition (passive monitoring)

Step 4 is the gorilla's ongoing role. fEAR continues sensing.
The bloom sensor on the sovereign sites observes which pages
receive traffic. DNS/WHOIS/CT-log monitors detect infrastructure
changes by targets. LARA periodic searches detect entity status
changes. The gorilla watches the decomposition unfold.
