# squirrel Interface — AI Compute Dispatch for guerillaGorilla

**How the legal primal dispatches to the AI compute primal.**
**squirrel is to guerillaGorilla what barraCuda is to hotSpring.**

---

## THE COMPOSITION

guerillaGorilla defines the domain logic — what legal existence IS, what
subsystems it contains, what the fEAR and STRIDe loops do.

squirrel provides the compute — the synthetic intelligence that processes
legal knowledge at machine speed.

The operator provides direction — pattern recognition, strategic intuition,
human psychology, and the decision of where to walk.

```
OPERATOR (direction, pattern recognition, psychology, execution)
    │
    ▼
guerillaGorilla (domain logic, subsystem taxonomy, fEAR+STRIDe loops)
    │
    ▼
squirrel (AI compute dispatch)
    │
    ├── Statute recall (MCL, USC, MCR, CFR)
    ├── Case law analysis (precedent, elements, defenses)
    ├── Document drafting (complaints, motions, FOIA, briefs)
    ├── Cross-referencing (PACER ↔ ROD ↔ LARA ↔ news ↔ social)
    ├── Strategic modeling (OPFOR reaction, settlement calculus)
    ├── Contract analysis (clause identification, violation mapping)
    └── Network mapping (entity relationships, financial flows)
```

## THE DISPATCH MODEL

squirrel dispatch follows the same pattern as barraCuda GPU dispatch:

### barraCuda (for comparison)

```
hotSpring (physics domain logic)
  → "Run SU(3) gauge theory at β=6.0 on 16⁴ lattice"
    → barraCuda (GPU dispatch)
      → WGSL shader compilation
      → Vulkan/WebGPU execution
      → f64 precision management
      → Cross-vendor abstraction (NVIDIA/AMD/Intel)
    ← Result: plaquette expectation value ⟨P⟩
  ← hotSpring validates against Necco-Sommer (0.3% agreement)
```

### squirrel (for guerillaGorilla)

```
guerillaGorilla (legal domain logic)
  → "Analyze PCA charter contract for background check violations"
    → squirrel (AI dispatch)
      → Contract text ingestion (OCR if scanned)
      → Clause identification (§ 10.07, § 3.06, § 5.12)
      → Statute cross-reference (MCL 15.181, MCL 380.1535a)
      → Violation mapping (Banks: no background check disclosure;
         Moreland: incompatible offices; Miller: same)
    ← Result: 3 specific violations with section citations
  ← guerillaGorilla validates against primary sources
     (PCA website screenshot confirms board composition)
```

The pattern is identical:
1. Domain primal formulates the question
2. Compute primal processes it
3. Result returns to domain primal
4. Domain primal validates against known baseline

## THEORY OF MIND — THE OPERATOR'S EDGE

The operator's relationship with squirrel is not "asking a chatbot for help."
It is theory of mind applied to a synthetic intelligence.

Theory of mind: the ability to attribute mental states (knowledge, capability,
limitation) to another entity and to use that model to direct interaction.

The operator understands:

**What squirrel is good at:**
- Comprehensive knowledge recall (statutes, case law, procedures)
- Rapid document generation (drafts in minutes, not days)
- Exhaustive cross-referencing (connecting PACER to ROD to LARA to news)
- Tireless processing (no fatigue, no billable hour pressure)
- Multi-domain awareness (simultaneous knowledge of federal RICO + Michigan
  family law + bankruptcy code + charter school governance)

**What squirrel is bad at:**
- Knowing when to stop (will keep generating if not directed)
- Human psychology (models behavior, doesn't *understand* it)
- Verifying its own outputs against reality (hallucination risk)
- Making judgment calls under ambiguity (defaults to caution)
- Understanding operator context that wasn't stated explicitly

**The operator's theory of mind produces optimal dispatch:**
- Ask squirrel for statute text → trust the output (it's good at recall)
- Ask squirrel for strategic prediction → verify against operator intuition
- Ask squirrel to draft a document → review for accuracy, sign off on tone
- Ask squirrel to cross-reference → trust the connections, verify the sources
- Ask squirrel "what should I do" → take as input, not as directive

This is the same operator skill used in COIST: you don't trust the satellite
image as ground truth. You trust it as intelligence that informs your analysis.
The analysis is yours. The satellite is a sensor. squirrel is a sensor.

## SUSTAINABILITY

squirrel's cost structure makes guerillaGorilla sustainable:

| Resource | squirrel cost | Traditional equivalent cost |
|---|---|---|
| One week of continuous operation | ~$20-50 API costs | $15,000-25,000 attorney time |
| OSINT brief production | ~$2-5 per brief | $5,000-15,000 investigator |
| Document drafting | ~$1-3 per document | $500-2,000 per document |
| Strategic analysis session | ~$3-8 per session | $500-1,000 per hour consultation |
| PACER cross-reference analysis | ~$1-2 per analysis | $200-500 paralegal time |

Total guerillaGorilla operating cost for Week 1 (Banks/Smith):
- squirrel (AI compute): ~$30-80
- PACER fees: ~$30-50
- Filing fees: ~$350
- Process service: ~$200-400
- Printing/mailing: ~$100-200
- **Total: ~$700-1,100**

Traditional equivalent for the same output:
- Attorney retainer: $5,000-10,000
- Private investigator: $5,000-15,000
- Litigation support: $3,000-8,000
- **Total: $13,000-33,000**

**Cost ratio: ~15-30× cheaper.** And the output is at least equivalent — the
OSINT brief alone exceeds what most investigators would produce in a month.

This is the same cost disruption as ecoPrimals: lattice QCD at $0.044/run
vs. $1,000s on institutional HPC. guerillaGorilla at $700/week vs. $13,000/week
for professional equivalent. The methodology is the same. The domain is different.
The cost reduction is structural.
