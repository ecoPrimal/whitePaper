# ecoPrimals Public Roadmap

This document outlines the strategic development phases for the ecoPrimals project. Our goal is to move from a collection of powerful, independent Primals to a unified, self-sustaining digital ecosystem. The roadmap is divided into four distinct, sequential phases.

---

### Phase 1: Foundation (Complete)

This phase focused on the creation and maturation of the core software components, the "Primals." The primary goal was to forge robust, well-architected, and feature-complete building blocks.

*   **`toadstool`**: A universal compute runtime.
*   **`nestgate`**: A sovereign, workspace-based storage system.
*   **`songbird`**: A universal networking and service coordination layer.
*   **`beardog`**: A comprehensive security orchestration platform.

**Status:** The foundational Primals are code-complete, individually tested, and represent a stable base for the next phase of integration.

---

### Phase 2: Unification

The objective of this phase is to fuse the individual Primals into a single, coherent operating system: `biomeOS`. The key deliverable is a "grandma-safe" interactive installer that makes the power of the ecosystem accessible to everyone.

*   **Milestone 2.1: `biomeOS` Core Daemon:** Develop the headless, API-driven core that manages the lifecycle and interaction of the Primals.
*   **Milestone 2.2: Interactive Installer (`egui`):** Create the pure-Rust, `egui`-based graphical installer.
    *   Implement "Playground Mode" for live configuration editing.
    *   Develop the "Ephemeral Key Sacrifice" ritual for secure key generation.
*   **Milestone 2.3: `iso-forge` Utility:** Build the tool for creating custom, bootable `biomeOS` distributions ("Niche Packages").
*   **Milestone 2.4: First Bootable ISO:** Produce the first official, bootable `biomeOS.iso`, capable of installing a fully functional, single-node instance.

**Goal:** Lower the barrier to entry to near-zero, enabling non-technical users to deploy their own sovereign infrastructure.

---

### Phase 3: Federation

With single-node instances established, this phase focuses on enabling them to securely connect, forming resilient, decentralized networks. This is where the "Friendship Network Superiority" thesis is put into practice.

*   **Milestone 3.1: Mesh Installation:** Implement the federated installer flow, allowing a new `biomeOS` instance to securely join an existing one via a proximity-based handshake.
*   **Milestone 3.2: Genetic Mixing:** Integrate the "genetic mixing" of cryptographic seeds during federation, creating a verifiable and secure lineage.
*   **Milestone 3.3: Service Discovery and Federation:** Extend the `songbird` protocol to enable seamless service discovery and communication across federated instances.
*   **Milestone 3.4: Distributed Governance Primitives:** Implement the foundational tools for network-level governance and decision-making.

**Goal:** Move from isolated sovereign nodes to a resilient, self-organizing, and cooperative digital ecosystem.

---

### Phase 4: Economy

This final phase focuses on activating the economic engine of the ecosystem, as defined in the `Latent Value Economy` whitepaper. The goal is to create a self-sustaining system that rewards contribution and unlocks the dormant value of user-owned hardware and data.

*   **Milestone 4.1: Loam Certificate Layer:** Deploy the core infrastructure for the "Loam Certificate Layer," enabling the minting and exchange of provably unique digital assets derived from user memory.
*   **Milestone 4.2: Sovereign Supercomputer:** Implement the resource-sharing protocols that allow users to contribute idle compute and storage to the network in exchange for value.
*   **Milestone 4.3: Market Integration:** Develop the initial user-facing applications and interfaces for participating in the new economy.
*   **Milestone 4.4: The Flywheel:** Demonstrate a positive feedback loop where the value generated by the network incentivizes further growth, contribution, and federation.

**Goal:** To establish a thriving, circular economy that is owned and operated by its participants, providing a sustainable alternative to centralized platforms.
