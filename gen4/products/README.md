## The sporeGarden Ecosystem

Every product is a different focus on the same validated foundation.
Springs validate the science. Primals provide the infrastructure.
Products compose them into tools people use.

```
Springs (science)    → evolve →  Primals (infrastructure)
                                        ↓
                              Products (user-facing tools)
                                        ↓
                              Spores (reproducible artifacts)
                                        ↓
                         Feed back → evolve → Springs
```

## Reading Order

1. **ESOTERIC_WEBB.md** — The first gen4 product. Read this to
   understand what a gen4 product looks like in practice.

2. **RPGPT_ENGINE.md** — The generalized living game system. Read this
   to understand how ingestible rulesets eliminate the developer
   bottleneck between tabletop design and digital execution.

3. **HELIX_VISION.md** — Sovereign genomics discovery. Read this to
   understand how the sporeGarden pattern applies to science — same
   primals, same PrimalBridge, different domain.

4. **BLUEFISH.md** — Sovereign PFAS/analytical chemistry ETL pipeline.
   Replaces vendor-locked Chromeleon with sovereign data processing.

5. **INITIOCHEM.md** — Interactive computational chemistry explorer.
   3D molecular visualization + GPU FEL computation via petalTongue +
   barraCuda. The first product driving petalTongue Phase 4.
